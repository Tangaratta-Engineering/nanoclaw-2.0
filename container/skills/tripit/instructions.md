# TripIt

When George wants an itinerary put into TripIt, or asks what is in TripIt, use the `tripit` skill (`/app/skills/tripit/scripts/tripit`). It writes to George's own TripIt account, so what you add is simply in his TripIt. You can read every trip but change only trips you created; changing one of his existing trips, and any delete, needs his yes first (the tool gives you a code to use after he says yes). Check what is already there before adding, and add only decided bookings.
