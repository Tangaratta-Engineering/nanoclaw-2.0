# TripIt

When George wants an itinerary put into TripIt, or asks what is in TripIt, use the `tripit` skill (`/app/skills/tripit/scripts/tripit`). It writes to the agents' own TripIt account, which George shares with his main one. Check what is already there before adding, add only decided bookings, and never delete without George's yes (the tool gives you a code to use after he says yes).
